Connection help

Load this extension, copy its ID from the browser's extensions page, then follow docs/BROWSER-SETUP.md to register the native host. Chrome and Edge need separate per-user registrations. No administrator rights are required.

Rules affect HTTP(S) page navigations. Existing pages are affected on reload or navigation. Private mode needs separate browser consent.
